# Product Guidelines: MixamoAnimator

## Design Principles
- **Clean & Functional:** Prioritize utility and ease of use over complex aesthetics. The interface should feel familiar and predictable.
- **Workflow Efficiency:** Minimize the number of clicks or steps required to load a model and apply an animation.

## User Experience (UX)
- **Interactive Feedback:** Provide clear, real-time feedback when a model is loaded or an animation is applied.
- **Action-Oriented Documentation:** Focus on practical, step-by-step instructions for the user.

## Error Handling
- **User-Friendly & Actionable:** Error messages should use simple language and provide clear instructions on how to resolve the issue (e.g., "Model file not found. Please check the path and try again.").

## Branding & Visuals
- **Consistency:** Use standard PyQt/PySide widgets and styles for a consistent desktop experience.
- **Clarity:** Ensure all labels and controls are easy to read and understand.
